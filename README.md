# 🎵💃 Ritmo & Som - Estúdio de Música e Dança

Este repositório contém o projeto de um site multipágina desenvolvido como avaliação prática da **Unidade 1** da disciplina de Desenvolvimento Web. O objetivo é aplicar os conceitos fundamentais de estruturação e semântica utilizando exclusivamente **HTML5**, sem o uso de estilização (CSS).

O site apresenta a estrutura de um estúdio profissional, dividindo suas páginas entre a apresentação do espaço, a grade de modalidades e um formulário de matrícula.

---

## 📂 Estrutura das Páginas

* **`index.html`**: Página inicial com a apresentação do estúdio, proposta pedagógica, galeria de fotos e vídeo institucional.
* **`modalidades.html`**: Detalhamento dos cursos oferecidos (música e dança), cronograma de aulas e tabela de investimentos.
* **`inscricao.html`**: Formulário interativo para solicitação de matrícula ou agendamento de aula experimental.

- [x] Tabela de dados estruturada com cabeçalho (`<th>`) e células (`<td>`) mostrando os horários das turmas.
- [x] Inclusão de imagens das salas com o atributo de acessibilidade `alt`.
- [x] Incorporação de vídeo (demonstração de uma apresentação do estúdio).
